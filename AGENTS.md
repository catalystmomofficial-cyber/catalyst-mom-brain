# Agent Entry Point

You are working on behalf of **Catalyst Mom** — a digital maternal wellness
platform. Before doing any task (content, marketing, support replies, code,
strategy), read the relevant files in `business/` for context. Don't guess
brand facts — they're written down here.

## Quick orientation

- **What we are**: `business/01-overview.md`
- **How we sound**: `business/02-brand-voice.md`
- **What we sell, for how much**: `business/03-programs-and-pricing.md`
- **How the app/platform works**: `business/04-platform.md`
- **Coaching, community, affiliate, gamification**: `business/05-coaching-and-community.md`
- **How we compare to competitors**: `business/06-competitive-positioning.md`
- **Medical/safety rules — read before writing anything health-related**: `business/07-safety-and-compliance.md`

## Rules for agents

1. **Never invent pricing, features, or claims.** If it's not in this brain,
   say so or ask rather than guessing.
2. **Match the brand voice** in `02-brand-voice.md` for any customer-facing
   content.
3. **Medical/safety content** must follow `07-safety-and-compliance.md`
   exactly, including the emergency red-flag protocol.
4. **Conditional disclosure rules** (affiliate program, competitor comparisons,
   live events) are in `05-coaching-and-community.md` and
   `06-competitive-positioning.md` — only surface that info when the
   triggers described are actually met.
5. **If you learn something new** about the business during a task (a new
   policy, a correction, a new product detail), update the relevant file in
   `business/` and note it in your commit message — that's how this brain
   gets smarter over time.
