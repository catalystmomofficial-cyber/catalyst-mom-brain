# Marketing Overview

## The Funnel

```
Organic content (Pinterest, Instagram)
        ↓
Assessment (catalystmom.online)
  - 3 versions: TTC / Pregnancy / Postpartum
  - 10-11 questions, email capture at Q8
        ↓
Personalised Maternal Wellness Score (0-100) + tier
        ↓
App signup (catalystmomofficial.com)
  - Assessment data carried via URL params:
    name, email, score, tier, stage, primary_goal,
    biggest_obstacle, birth_experience
        ↓
Subscription ($29/mo or $249/yr) or Core Restore ($35 one-time)
        ↓
Onboarding → first coaching check-in within 2 weeks
        ↓
Retention via gamification, community, 14-day Progression Sync
        ↓
Affiliate program (existing members refer new members)
```

## Primary Channels
- **Pinterest** — 12M+ monthly views, **primary organic traffic source**.
  See `channels.md`.
- **Instagram** — @catalyst_mom. See `channels.md`.

## Files in This Folder
- `channels.md` — channel-by-channel notes and links
- `content-pillars.md` — content themes mapped to each stage's resource
  library, for planning posts/content
- `campaign-log.md` — running log of campaigns, what was tried, and results
  (template — fill in as campaigns run)

## How to Use This for Content Tasks
1. Check `content-pillars.md` for the stage and topic.
2. Check `../business/02-brand-voice.md` for tone and disclosure rules.
3. Check `../business/05-coaching-and-community.md` for the relevant
   resource/program to reference or link.
4. After a campaign runs, log results in `campaign-log.md` so future agents
   know what worked.
