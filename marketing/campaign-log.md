# Campaign Log

Running log of marketing campaigns/content pushes and their results. Add a
new entry per campaign. This is the "memory" that lets agents avoid repeating
what didn't work and double down on what did.

## Template

```md
## YYYY-MM-DD — Campaign Name
- **Channel:** Pinterest / Instagram / Email / Paid / etc.
- **Stage targeted:** TTC / Pregnancy / Postpartum / All
- **Content pillar:** (see content-pillars.md)
- **Goal:** e.g. drive assessment completions, grow followers, promote
  Core Restore $35 offer
- **What was done:** brief description, link to creative if available
- **Result:** metrics (views, clicks, assessment completions, conversions,
  cost if paid)
- **Takeaway:** what to repeat / avoid next time
```
